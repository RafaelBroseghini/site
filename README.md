# rafaelbroseghini.com

Personal blog by Rafael Broseghini — notes on cloud-native tooling, homelab projects, side projects, and things I'm still figuring out.

Live site: [rafaelbroseghini.com](https://rafaelbroseghini.com)

## Development

Requires Node `>=22.12.0`.

```bash
npm install
just dev      # or: npm run dev
just build    # production build
just preview  # preview the build locally
```

See the [justfile](justfile) for other commands.

Built with [Astro Paper](https://github.com/satnaing/astro-paper).
